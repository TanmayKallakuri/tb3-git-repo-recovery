# orbit API

Generated by tools/gen_api_docs.py from the package docstrings; do not edit.

## orbit

orbit: a small scheduler for periodic jobs.

Jobs are declared with a cron expression and a command line; the scheduler
runs them in order, records the outcome and reports what failed.

## orbit.cron

Parse five-field cron expressions into sets of allowed values.

### class CronError

Raised for an expression that cannot be parsed.
